# DashboardK

A modern and responsive admin dashboard designed to provide a clean and intuitive interface for managing business information, monitoring performance, and visualizing data.

## Preview

DashboardK is a dashboard interface focused on usability, organization, and modern design, featuring a dark visual identity and interactive components.

## Features

- Modern dark-themed interface
- Responsive sidebar navigation
- Dashboard overview
- Interactive charts and data visualization
- Analytics section
- Activity history
- Products management interface
- Profile menu and dropdown interactions
- Responsive layout

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js

## Design

The interface uses a modern dark aesthetic, with carefully organized sections, smooth transitions, and a focus on readability and usability.

## Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/eukiq/dashboardk.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server or your preferred local development environment.
